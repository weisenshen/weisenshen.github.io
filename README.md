# Weisen Shen Personal Website

This is a lightweight static website for Dr. Weisen Shen. It is designed to be easy to maintain and can be hosted on GitHub Pages or any static web host.

## Structure

- `index.html` contains the site content and page sections.
- `styles.css` controls the visual design.
- `script.js` controls the mobile menu and active navigation state.
- `assets/resume/weisen-shen-resume.pdf` is the expected location for the latest resume PDF.

## Updating the Resume

Create the folder `assets/resume` if it does not exist, then place the latest PDF at:

```text
assets/resume/weisen-shen-resume.pdf
```

The resume button on the site already points to that path.

## Updating Publications

The current publication section links to Google Scholar:

```text
https://scholar.google.com/citations?user=MDDt0q8AAAAJ&hl=en
```

A curated publication list or BibTeX-based workflow can be added later.
